# Entrega — 13/08/2026

Esta versão foi reconstruída sobre o layout existente, sem redesign.

## Alterações
- Área pública de sócios antes do login, organizada por Futebol/Futsal e categoria; categorias vazias não aparecem.
- Hover no desktop e toque no mobile para abrir a lista de nomes.
- Administração permite alterar o número de sócio através da RPC segura `admin_alterar_numero_socio`.
- Importação de quotas Excel validada e com suporte a valor.
- Importador de quotas corrige a identificação do administrador (`user_id`) e grava `valor`.
- Função de aniversário `aniversarios` com proteção contra envio duplicado por ano.
- Drº Árbitro: inicialização administrativa corrigida para chamar efetivamente `adminInit`; inicialização do sócio reage ao login.
- Migration central para dados públicos, quotas, alteração de número e controlo de aniversários.
- Remoção de ficheiros placeholder/teste de 1 byte e da Edge Function de teste duplicada.
- Verificação de sintaxe JavaScript realizada nos módulos alterados.
